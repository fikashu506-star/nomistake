# NoMistake

Arcade mengetik Bahasa Indonesia — 4 mode:

- **Mode Level** — 10 level progresif, kumpulkan bintang
- **Hujan Kata** — ketik sebelum kata menyentuh dasar
- **Waktu Kilat** — 60 detik, secepat mungkin
- **Mode Zero** — satu kesalahan = game over

## Main di browser

Buka `index.html` langsung, atau aktifkan **GitHub Pages**:

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

Lalu buka: https://fikashu506-star.github.io/nomistake/

## Tech

Single-file HTML + CSS + JS, tanpa framework. Progres tersimpan di perangkat (localStorage).
